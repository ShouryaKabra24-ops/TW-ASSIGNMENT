# Google Docs

## Introduction

Google Docs is an online word processor provided by Google Workspace. It allows users to create, edit and share documents from different devices.

It is commonly used for assignments, reports, meeting notes and collaborative projects.

## Features

- Real-time collaboration.
- Document formatting and templates.
- Comments and suggestions.
- Automatic saving.
- Version history.
- Sharing and access permissions.
- Exporting documents into different formats.

## Creating a Document

1. Open https://docs.google.com.
2. Select Blank Document or choose a template.
3. Enter your content.
4. Use the formatting toolbar to organize the document.

## Formatting and Styles

Google Docs provides different text styles:

| Style | Purpose |
|---|---|
| Title | Main document title |
| Subtitle | Additional title information |
| Heading 1 | Main sections |
| Heading 2 | Subsections |
| Normal Text | Regular paragraphs |

Using heading styles keeps the document organized and helps generate a table of contents automatically.

## Collaboration and Sharing

Click the **Share** button to invite other users through email or a link.

Google Docs provides three main access permissions:

| Permission | Description |
|---|---|
| Viewer | Can read the document |
| Commenter | Can add comments |
| Editor | Can make changes |

Comments and Suggesting mode help users review documents without directly changing the original content.

## Version History

Google Docs automatically saves changes.

To access previous versions:

1. Open File.
2. Select Version History.
3. Click See Version History.
4. Choose an earlier version to view or restore.

You can also give important versions names, such as Draft or Final Submission.

## Inserting Elements

The Insert menu provides options to add:

- Images from your computer or Google Drive.
- Tables for organizing information.
- Drawings and diagrams.
- Links and footnotes.
- Mathematical equations.

For code snippets, a monospace font can be used.

## Citations and Bibliography

Google Docs includes a citation tool.

Steps:

1. Open Tools → Citations.
2. Select a citation style such as APA, MLA or Chicago.
3. Enter the source details.
4. Insert citations into the document.
5. Generate a bibliography.

## Exporting Documents

Google Docs supports several file formats:

- PDF
- DOCX
- ODT
- RTF
- HTML
- TXT

To download a document, select:

**File → Download → Choose Format**

Documents can also be published to the web.

## Integrations

Google Docs works with other tools and services, including:

- Google Drive
- Google Calendar
- Google Meet
- Google Forms
- GitHub through available integrations
- Google Apps Script for automation

## Best Practices

- Use consistent formatting throughout the document.
- Organize content with headings.
- Add a table of contents for longer documents.
- Review comments and suggestions.
- Give collaborators appropriate permissions.
- Keep important versions and export final documents.
